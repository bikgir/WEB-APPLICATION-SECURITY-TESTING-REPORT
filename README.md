**WEB-APPLICATION-SECURITY-TESTING-REPORT**


This report documents a controlled security assessment of the Metasploitable 2 virtual machine (10.0.0.6). The assessment focuses on exposed services and web application functionality in the authorized laboratory environment. The supplied assessment material includes screenshots from DVWA demonstrating several security-testing modules.
The integrated evidence covers Brute Force, Command Execution, SQL Injection, File Upload, and Reflected Cross-Site Scripting (XSS). The supplied material does not contain a CSRF screenshot or network-service scan output, so those areas remain pending verification rather than being reported as confirmed findings.
